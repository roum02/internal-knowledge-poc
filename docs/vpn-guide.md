# 재택근무 VPN 접속 안내

이 문서는 RAG PoC를 위한 가상의 회사 규정입니다.

집이나 외부에서 사내 시스템에 접속하려면 회사에서 지급한 노트북으로 VPN에 연결합니다.
회사 소프트웨어 센터에서 VPN 클라이언트를 설치한 뒤 회사 계정으로 로그인하고
인증 앱에 표시된 일회용 코드를 입력합니다. 연결 상태가 'Connected'이면 사내 시스템을 이용할 수 있습니다.

접속이 실패하면 인터넷 연결과 기기의 날짜 및 시간을 먼저 확인합니다.
다시 로그인해도 실패하면 오류 메시지와 발생 시각을 사내 IT 지원 게시판에 남깁니다.
비밀번호나 일회용 인증 코드는 문의 내용에 포함하지 않습니다. 업무가 끝나면 VPN 연결을 해제합니다.
